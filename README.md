# Atelier

Application personnelle et multi-utilisateur en français pour centraliser projets, assistants, mémoire, fichiers et services de développement.

Développement en cours. Le cahier des charges, l’avancement et les validations sont conservés dans `docs/`. Cette première étape n’est pas la livraison finale.

Cible : Cloudflare Workers + D1 + R2 + Queues, interface React PWA responsive Android, iOS et ordinateur. Le propriétaire effectuera lui-même le déploiement. Aucun déploiement automatique n’est configuré.

Les connecteurs API ne représentent pas une connexion aux abonnements ou à l’historique privé des applications grand public. Codex App Server et Claude Code nécessitent un environnement d’exécution isolé distinct.

Voir `AGENTS.md` et `CLAUDE.md` pour reprendre le travail sans perdre les exigences.
